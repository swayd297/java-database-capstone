# Smart Clinic Management System - User Stories

## Admin User Stories
1. As an admin, I can add a new doctor to the system so that patients can book appointments with them.  
2. As an admin, I can update doctor details so that the information remains accurate.  
3. As an admin, I can deactivate a doctor’s profile so that inactive doctors cannot receive bookings.  
4. As an admin, I can view all registered patients so that I can monitor system usage.  
5. As an admin, I can generate reports on daily appointments so that management can analyze performance.

---

## Doctor User Stories
1. As a doctor, I can log in securely so that I can access my dashboard.  
2. As a doctor, I can view all upcoming patient appointments so that I can prepare for consultations.  
3. As a doctor, I can add prescriptions for patients so that medication is recorded properly.  
4. As a doctor, I can update my available time slots so that patients can book only valid times.  
5. As a doctor, I can view patient medical history so that I can make informed decisions.

---

## Patient User Stories
1. As a patient, I can register an account so that I can access the clinic services.  
2. As a patient, I can log in and select my preferred doctor so that I can book an appointment.  
3. As a patient, I can view my upcoming appointments so that I can prepare for my visits.  
4. As a patient, I can cancel an appointment so that the doctor’s schedule is updated.  
5. As a patient, I can view prescriptions provided by my doctor so that I can follow treatment instructions.
